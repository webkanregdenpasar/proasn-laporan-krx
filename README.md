# BKN ProASN RMS

This is a Record Management System (RMS) for Berita Acara Penyelenggaraan ProASN, built using:
- Next.js (frontend & routing)
- Firebase Firestore (database)
- Firebase Storage (photo uploads)
- Hosted on Vercel

## Setup
1. Run \`npm install\`
2. Add your Firebase config in \`.env.local\`
3. Run \`npm run dev\` to start locally
4. Deploy to Vercel
